## Getting Started

Clone the repository:

```bash
git clone https://github.com/Chetanbhagat21/Machine-Learning.git
cd Machine-Learning
```

Create and activate a virtual environment:

```bash
python -m venv venv
source venv/bin/activate   # On Windows use: venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run your notebook or Python script:

```bash
jupyter notebook
# or
python main.py
```
